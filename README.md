## About DeFi Investment Calculator

DeFi Investment Calculator is a browser-based finance tool built to help users estimate the possible outcomes of DeFi positions. It is focused on practical scenarios such as liquidity pools, trading fees, impermanent loss, and compounding effects, giving a clearer view of how a strategy may perform over time.

The tool is suited for crypto users who want a simple way to compare assumptions before committing capital. Because it runs in the browser and stores inputs in local browser cache, it is convenient for repeat analysis without re-entering the same values every session.

No external config file is required for normal use.
